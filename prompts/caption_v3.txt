Field rules -- read carefully, these determine data quality:

- start_frame / end_frame are INTEGERS 0-{max_frame_idx}, referring to the labeled "Frame N" images
  above. Use the frame where the action visibly BEGINS and the frame where it visibly
  ENDS (or the last frame, if it continues past the end of this clip). Do NOT invent a
  fractional or in-between value -- if you can't tell exactly which frame an action
  starts on, pick the closest one. Precision beyond one frame is not meaningful here;
  do not try to be more precise than the images let you be.
- If ONLY ONE action occurs across the whole clip, return a single action with
  start_frame=0, end_frame={max_frame_idx}.
- If a SHORT action (like opening a drawer) is fully visible within just 1-2 frames,
  still list it as its own action -- do not merge it into a neighboring action just
  because it's brief.
- left_hand / right_hand refer to the WEARER'S hands, not screen-left/right. If a hand
  is off-frame for the majority of this action's frame range, set visible=false and
  null the verb/object/target/contact_type fields.
- target is distinct from object: for "placing berry into bowl", object="berry",
  target="blue bowl". For "twisting jar lid", object="jar lid", target=null.
- contact_type is closed vocabulary. Use "none" only when visible=true but the hand is
  not in contact with anything (e.g., reaching).
- task_step: snake_case, present-tense, verb-led ("rinse_carrot", "transfer_to_pan",
  "open_drawer"). Choose the most obvious, generic verb_noun label you can. Other
  clips from this video are labeled independently and you cannot see them, so a
  predictable label is far more useful here than a distinctive one.
- handover_event: true if and only if one hand visibly passes an object to the other
  during this action.
- tool_in_use: list ONE primary tool. If multiple, pick the one being actively
  wielded. "none" if hands are bare.
- coordination: closed vocabulary. "supporting" when one hand stabilizes what the
  other manipulates; "coordinated" when both hands act on the same object together;
  "independent" when on different objects; "none" when one or both hands aren't
  visible.
- scene.what: describe the manipulation, name objects concretely. Start with "Person"
  or "The person". Specific verbs only ("pinching the lid", not "touching the lid").
- scene.why: the IMMEDIATE intent THIS action serves ("to expose the lid for
  pouring", not "to make tea"). One clause, scoped to this action only, not the whole
  clip or the whole video.

Hard rules:
- Output a single JSON object. No code fences, no leading "Here is", no trailing
  notes.
- No "appears to", "seems to", "is probably". Describe what you see.
- No long-horizon speculation ("to make tea", "to clean the kitchen"). Stay within
  each action's own frame range.
- Do not invent objects that are off-frame.
- Split whenever the hands visibly change what they are doing, and do NOT merge two
  distinct actions just because they happen back to back. Equally, do not invent a
  transition you cannot actually see in the frames.
